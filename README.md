# OBS-DockSnap

Save and restore dock layouts in OBS Studio 32.0.4.

- Save, load, overwrite, rename and delete layout snapshots.
- Restore dock positions, sizes, visibility, tabs and floating state, plus the main window position and size.
- Drag to reorder. Assign hotkeys to open the manager, load a snapshot, or cycle through snapshots.
- Numbered rows, modification times and name or #number search. Enter loads a match. In the list, F2 renames and Delete asks before deleting.
- Import and export JSON files. Manage up to 1,000 snapshots.
- English, Simplified Chinese and Traditional Chinese, following the OBS language.

Download the Windows x64 or macOS ARM64 ZIP from [Releases](https://github.com/iesv/OBS-DockSnap/releases/latest). Close OBS, extract the ZIP and run the included installer. On Mac, run the SH file with Bash. Restart OBS and open **Tools → DockSnap**.
